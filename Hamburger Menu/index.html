Resize the window to see the mobile menu

Shrink the browser width (or view on a phone) to swap the desktop links for the hamburger button. Tap it to see the icon morph into an X while a full-screen menu reveals itself from the corner, with each link animating in with its own stagger.

Tap the hamburger again to close — the same circular reveal collapses back into the button, and the icon morphs back from an X to three lines.
